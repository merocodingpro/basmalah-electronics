# سنتر بسملة للأجهزة الكهربائية 🏪⚡
### موقع إلكتروني متكامل للعملاء ولوحة تحكم لصاحب المحل (RTL بالكامل)

موقع وتطبيق ويب متكامل مصمم بالكامل باللغة العربية وموجه للجمهور في مصر، مبني بأحدث تقنيات الويب (**Next.js 14 App Router + Tailwind CSS + TypeScript**)، ومتجاوب 100% مع كافة أحجام الشاشات وتحديداً الموبايل (Mobile-First).

---

## 🎨 هوية التصميم والألوان
- **الأزرق الملكي (`#1E40AF`)**: للهيدر، وشريط التنقل، والأزرار والروابط الأساسية.
- **الأحمر الداكن (`#DC2626`)**: لشارات الخصومات، وزر "اطلب الآن"، والتنبيهات، وعروض اليوم.
- **خط عربي عصري**: خط **Cairo** المعتمد من Google Fonts.
- **دعم RTL أصلي**: كافة المكونات والنصوص من اليمين إلى اليسار.

## 🌟 مميزات موقع العملاء (المتجر)
1. **الصفحة الرئيسية (`/`)**:
   - هيدر متكامل مع لوجو "سنتر بسملة"، وبحث سريع، ورقم هاتف المحل، وزر تواصل واتساب مباشر.
   - بانر سلايدر عروض تفاعلي (Carousel) يعرض أقوى العروض الحصرية.
   - أقسام الأجهزة الكهربائية (ثلاجات، غسالات، شاشات، بوتجازات، أجهزة صغيرة).
   - قسم العروض والتخفيضات الخاصة، وقسم الأجهزة التي وصلت حديثاً.
   - نافذة منبثقة سريعة (Modal) لطلب أي جهاز مباشرة بنقرة واحدة.

2. **صفحة المنتجات (`/products`)**:
   - كروت عرض عصرية للأجهزة (صورة عالية الجودة، الاسم، السعر الحالي، السعر قبل الخصم، نسبة الوفر، وحالة التوفر).
   - فلترة حسب القسم بلمسة واحدة.
   - بحث فوري بالاسم أو الموديل.
   - ترتيب بالسعر (من الأقل للأعلى، من الأعلى للأقل، أو الأحدث).

3. **صفحة تفاصيل المنتج (`/products/[id]`)**:
   - معرض صور الجهاز المصغرة والكبيرة.
   - جدول المواصفات الفنية الكاملة (الماركة، السعة، الضمان، إلخ).
   - قائمة المميزات والتقنيات (انفرتر، نوفروست، سمارت).
   - زر "اطلب الآن (الدفع عند الاستلام)" وزر مراسلة واتساب فورية للاستفسار.

4. **صفحة مناطق التوصيل (`/delivery`)**:
   - جدول بطاقات لكافة المحافظات والمناطق المدعومة مع سعر ومدة التوصيل.
   - إرشادات ونصائح استلام الأجهزة وفحص شهادة الضمان والكرتونة قبل الدفع.

5. **صفحة ونموذج إتمام الطلب (`/checkout`)**:
   - بدون الحاجة لتسجيل دخول أو إنشاء حساب (تجربة شراء سريعة بدون تعقيد).
   - اختيار المحافظة والمنطقة مع احتساب مصاريف الشحن والإجمالي تلقائياً.
   - الدفع نقداً عند الاستلام.
   - بعد الإرسال، تظهر شاشة تأكيد فورية برقم الطلب مع رابط مباشر لمتابعة الطلب على واتساب.

6. **صفحة اتصل بنا (`/contact`)**:
   - أرقام الهاتف والاتصال المباشر.
   - زر واتساب مباشر.
   - العنوان وساعات العمل اليومية.
   - نموذج استفسار وخريطة تفاعلية للمعرض.

## 🛡️ مميزات لوحة تحكم صاحب المحل (`/admin`)
1. **حماية وتسجيل دخول آمن**:
   - صفحة تسجيل دخول محمية بجلسات (Cookies HttpOnly) عبر البريد وكلمة المرور.
   - **البريد الافتراضي:** `admin@basmalah.com`
   - **كلمة المرور الافتراضية:** `Basmalah@2025`
   *(يمكن تعديلها بسهولة من ملف `.env.local`)*

2. **لوحة الإحصائيات العامة (`/admin`)**:
   - عدد طلبات اليوم وطلبات هذا الأسبوع.
   - إجمالي المبيعات وقيمة الأجهزة المسلمة.
   - الأجهزة الأكثر طلباً وإجمالي القطع المطلوبة منها.
   - ملخص بحالات الطلبات الحالية.

3. **إدارة المنتجات والأجهزة (`/admin/products`)**:
   - إضافة جهاز جديد مع رفع/إدخال رابط الصورة، والاسم، والقسم، والسعر، ونسبة الخصم، والمخزون.
   - **تعديل سريع للسعر مباشرة من الجدول (Inline Quick Price Edit)** بنقرة واحدة وحفظ فوري!
   - زر إظهار/إخفاء المنتج من المتجر بضغطة زر.
   - تعديل وحذف الأجهزة.

4. **إدارة مناطق وأسعار الشحن (`/admin/delivery`)**:
   - إضافة مناطق ومحافظات جديدة، وتحديد سعر التوصيل والمدة المتوقعة لكل منطقة.

5. **إدارة الطلبات (`/admin/orders`)**:
   - جدول متكامل بجميع الطلبات الواردة مرتبة من الأحدث للأقدم.
   - **رقم العميل قابل للضغط المباشر للاتصال به هاتفياً بنقرة واحدة (`tel:`)**.
   - **زر مراسلة واتساب العميل فورياً برسالة مجهزة مسبقاً برقم طلبه**.
   - تغيير حالة الطلب مباشرة من الجدول بنقرة واحدة:
     - 🔴 جديد
     - 🔵 تم التواصل هاتفياً
     - 🚚 في الطريق للشحن
     - ✅ تم التسليم بنجاح
     - ❌ ملغي
   - نافذة تفاصيل الطلب الكاملة.

6. **إشعارات صوتية وبصرية فورية للطلبات**:
   - نظام فحص تلقائي داخل لوحة التحكم (كل 12 ثانية).
   - تشغيل **نغمة رنين / جرس تنبيهي صوتي لطيف (Audio Chime)** بمجرد وصول طلب جديد عبر Web Audio API دون الحاجة لملفات صوت خارجية.
   - إشعار بصري (Toast Notification) يظهر برقم الطلب واسم العميل.
   - إمكانية كتم أو تفعيل الصوت وزر لتجربة النغمة من الهيدر.

## 📱 إشعارات الطلبات الفورية على هاتف صاحب المحل
الموقع يدعم إرسال إشعار فوري لحظة قيام العميل بالطلب عبر **Telegram Bot API**:

### محتوى الرسالة التلقائية:
```text
🛒 طلب جديد رقم #BM-1004
────────────────────
📦 المنتجات:
▫️ ثلاجة شارب 450 لتر نوفروست (الكمية: 1) - 34,500 ج.م

💰 الإجمالي: 34,650 ج.م (شامل مصاريف الشحن 150 ج.م)
👤 اسم العميل: أحمد محمود
📞 رقم العميل: 01012345678 (قابل للضغط المباشر للاتصال)
💬 مراسلة واتساب العميل: اضغط هنا
📍 مكان التوصيل: القاهرة - مدينة نصر
🏠 العنوان بالتفصيل: شارع مكرم عبيد، عمارة 12 الدور الثالث
⏰ التاريخ: 10/11/2026, 08:45 م
────────────────────
سنتر بسملة للأجهزة الكهربائية
```

### خطوات تفعيل بوت تليجرام في دقيقتين:
1. افتح تطبيق تليجرام وابحث عن `@BotFather`.
2. أرسل الأمر `/newbot` ثم اختر اسماً للبوت، وانسخ الـ **Token** الذي سيظهر لك.
3. لمعرفة رقم الـ **Chat ID** الخاص بك، راسل البوت `@userinfobot` وسيخبرك بالرقم الخاص بك.
4. ضع التوكن والـ ID في ملف `.env.local`:
   ```env
   TELEGRAM_BOT_TOKEN=123456789:ABCDefgh-IJKLMnopQRStuv
   TELEGRAM_CHAT_ID=123456789
   ```
5. بمجرد قيام أي عميل بطلب جهاز، ستصلك الرسالة فوراً على تليفونك مع إمكانية الضغط على رقم العميل للاتصال به أو فتح محادثة واتساب معه فوراً!

## 🚀 طريقة التشغيل محلياً (Quick Start)

### 1. المتطلبات
- تثبيت Node.js (الإصدار 18 أو 20 أو أحدث).

### 2. تثبيت الحزم (إن لم تكن مثبتة)
```bash
npm install
```

### 3. تشغيل خادم التطوير
```bash
npm run dev
```

افتح المتصفح على الرابط:
- **واجهة متجر العملاء:** [http://localhost:3000](http://localhost:3000)
- **لوحة التحكم:** [http://localhost:3000/admin](http://localhost:3000/admin)

### 4. بناء المشروع للإنتاج (Production Build)
```bash
npm run build
npm start
```

## 🗄️ قاعدة البيانات وتخزين البيانات
- يعمل الموقع **تلقائياً وبشكل فوري** باستخدام ملف قاعدة بيانات محلي فائق السرعة (`data/store.json`)، مما يعني أنك لست بحاجة لإنشاء حساب خارجي لتبدأ بتعديل وإضافة المنتجات فوراً وتظل البيانات محفوظة ومستمرة.
- تم تزويد الموقع أيضاً بملف **`supabase-schema.sql`** جاهز للاستخدام ومزود بكافة الجداول والفهارس في حال رغبتك بالربط مع قاعدة بيانات **Supabase**.
